# PINK HUB — 방송인 공식 홈페이지

보안 중심 설계와 핑크 테마로 구성된 방송인 공식 홈페이지입니다.

## 주요 기능
- **홈**: 실시간 방송 상태 배너(LIVE/OFFLINE), 최신 공지, 다가오는 일정, 내 포인트 요약
- **공지사항 / 게시판**: 탭별 커뮤니티(공지, 자유, 팬아트, 클립, 질문/건의), 검색, 댓글
- **시그니처**: 별풍선 개수별 시그니처 리액션 도감
- **캘린더**: 월간 방송 일정 달력 및 상세 리스트
- **포인트 시스템 & SOOP 연동**:
  - 자체 회원가입/로그인 + 선택적 **SOOP 아이디 인증 코드 연동** (`!인증 PINK-XXXX`)
  - 일일 출석체크(+50P), 게시글 작성(+10P), SOOP 채팅 참여(+5P, 5초 도배 방지 쿨타임 및 일일 상한 적용)
  - 포인트 상점 교환 및 전체 포인트 원장(Ledger) 기록
- **관리자 대시보드**: 방송 상태 변경, 공지/시그니처/일정 등록, 회원 포인트 수동 지급/회수, 상점 교환 승인/반려

## 실행 방법
```powershell
.\.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8000
```
브라우저에서 `http://127.0.0.1:8000` 접속
